# マインスイーパー穴埋め教材

出典: https://github.com/Ktomoya912/HCHS （参照コミット: 460a2ee65cc6c89651a62dfc796849328e98673f）
対象: 変数、if、for、リスト、関数、クラスの基本を学んだPython初学者。

## 配布と実行

生徒にはstudentフォルダを配布してください。answerフォルダとANSWERS.mdは教員用です。
student/mine_sweeper.pyの問01〜23、student/gui.pyの問24〜25を埋めます。
`____01____`などを、コメントが示す処理に合うPythonの式・値・メソッド名に置き換えてください。
未完成のまま起動するとNameErrorなどが発生します。すべての穴を埋めてから起動してください。

```bash
python -m pip install pygame
cd student
python gui.py
```

Python 3とtkinterが必要です。Linuxでは環境によってtkinterの追加導入が必要です。
左クリックで開き、右クリックで旗を立てる・外す操作ができます。
GUIの盤面サイズはgui.pyのboard_width、board_heightで変更できます。
最初のクリックで地雷を引く場合もあります。

## 取り組む順序

1. 問01〜04: Tileの初期状態。
2. 問20〜23: 盤面の端を判定する。
3. 問05〜09: 地雷配置、周囲の地雷数、座標とリスト番号。
4. 問10〜14: マスを開く、ゲームオーバー、クリア。
5. 問15〜17: 旗と残り枚数。
6. 問18〜19: 周囲の自動オープン（発展）。
7. 問24〜25: GUIからゲーム処理を呼び出す。

横幅4の場合、1行目の番号は0〜3、2行目は4〜7です。(x=2,y=1)は番号6です。
set_adjacent_minesのiは縦、jは横の移動量（-1,0,1）です。
open_zero_tilesは自分自身を呼ぶ「再帰」を使います。先に開いた状態にすることで同じマスを何度も処理するのを防ぎます。
再帰が未習の場合は問18〜19を教員と一緒に埋め、他の問題を先に解いてください。
GUIの描画やイベントループは記入済みです。GUI自体の書き方は課題の中心にしていません。

## 完成後に確かめること

- 数字が周囲8マスの地雷数になっているか。
- 地雷を開くと終了するか。
- 旗があるマスは左クリックや自動オープンで開かないか。
- 残りの旗が0でも、すでにある旗を外せるか。
- 地雷以外をすべて開くとクリアするか。

## 元コードからの教材用調整

クラス名・主要メソッド名・1次元リスト構造・Pygame GUIを維持しています。
CUI専用の色表示と入力ループは省きました。is_opendは元コードの綴りを維持しています。
旗のあるマスの自動オープン、開いたマスへの旗、残り旗数の制限、終了後の操作を修正しました。
再生成時は盤面・勝敗・計時を初期化し、地雷を開いたときはGUIに地雷を表示します。
GUIのTk生成は起動時に移し、終了処理と60FPSの制限を追加しました。
